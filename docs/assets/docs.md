# `docs/assets` — brand assets

| File | Use |
|---|---|
| `logo.svg` | App mark (chat bubble + lock, Ice → Cyan → Ocean → Navy gradient, amber "online" dot). Also shipped as `apps/web/public/{logo,favicon}.svg` and drawn by the `Logo` React component. |
| `logo-wordmark.svg` | Mark + "Enclave" wordmark in Ocean Blue (README, documentation). |

Palette: Deep Navy `#17324D`, Ocean Blue `#2596BE`, Soft Cyan `#8BD3E2`, Warm Amber `#F2B66D`,
Ice White `#F4F8FA` (source of truth: `apps/web/src/ui/theme/tokens.ts`). Keep the mark legible at
16 px; do not add text inside it.
